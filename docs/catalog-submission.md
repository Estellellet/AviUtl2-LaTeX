# AviUtl2カタログ登録チェックリスト

- [ ] パッケージ名: AviUtl2LaTeX
- [ ] 作者名: リリース前に確定
- [ ] 概要・詳細説明をREADMEと一致させる
- [ ] GitHubリポジトリURLを入力
- [ ] GitHub Releases URLを入力
- [ ] ライセンス: MIT
- [ ] 対応AviUtl2バージョン: RequiredVersion `2.00.3300`以降
- [ ] 配布ZIP名: `AviUtl2LaTeX-vX.Y.Z.zip`
- [ ] ZIP内配置: `AviUtl2LaTeX/AviUtl2LaTeX.auf2`ほか文書
- [ ] 外部依存: LuaLaTeX（MiKTeXまたはTeX Live）とMuPDFのmutool
- [ ] 外部ツール・フォントを同梱していないことを確認
- [ ] GitHub Releasesを更新元として登録
- [ ] スクリーンショット候補: 数式、累積表示、TikZ、環境設定、フォント選択
- [ ] 不具合報告先（GitHub Issues）を入力
- [ ] ZIPとSHA-256をReleaseへ添付

カタログ固有の登録データ形式はプラグインへ埋め込まず、公開時点の登録画面に従って入力する。
